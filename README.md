# ML-CCC-BankChurn

*Primer proyecto del curso de Machine Learning*

---

Este repositorio contiene el primer proyecto del curso de Machine Learning. El objetivo es predecir qué clientes de tarjeta de crédito tienen alta probabilidad de abandonar el banco, usando el dataset público **Credit Card Customers** (https://www.kaggle.com/datasets/sakshigoyal7/credit-card-customers) de Kaggle.

El trabajo cubre el ciclo completo de un problema de clasificación con clases desbalanceadas: análisis exploratorio con conclusiones de negocio, comparación de regresión logística, Random Forest y gradient boosting mediante validación cruzada, selección de un umbral de decisión con criterio de negocio, interpretación de las variables más importantes en lenguaje no técnico y generación de un archivo de predicciones por cliente para un dashboard en Tableau. Desarrollado en Python con pandas y scikit-learn, con el código en `src/` y el análisis en sus respectivos notebook.
